Shinya Dev

Mini Apps for World App

A small studio building lightweight, single-purpose Mini Apps for the World App ecosystem. All apps are designed for verified humans, run inside World App via the MiniKit SDK, and integrate with World ID for sybil resistance.

About

Shinya Dev is an indie developer studio based in Japan. Each Mini App is built end-to-end by a single developer with a focus on shipping fast, useful tools that respect user privacy.

Stack:
Next.js · React · TypeScript · Tailwind · Supabase
Identity:
World ID via MiniKit SDK
Hosting:
Vercel
Principle:
One job per app, done well.
